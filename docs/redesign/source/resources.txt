A number without a denominator is a slogan.
Every figure in these studies names the population it was measured over, the window it was measured in, and the baseline it moved from. If we cannot state all three, we do not publish the number.
The baseline comes first
We measure the workflow before we touch it, out of the client's own reporting rather than ours. Where there is no baseline, making one is the first week of the build.
The same population, after
After is measured on comparable volume over a stated window — ninety days, a quarter, six months. Never a hand-picked fortnight, and never a projection.
The client's own dashboard
Every metric here is one the client already tracked before we arrived, so nobody has to trust a figure we invented to describe our own work.
